# ADR（設計判断の記録）

設計判断を 1 件ずつ記録する。現在の設計の正本は `ARCHITECTURE.md` で、ここは判断の履歴である。

## 書式

ファイル名は `NNNN-<題>.md`（`NNNN` は 4 桁の連番）。中身は次の節を持つ。

- 背景: なぜ判断が要ったか
- 判断: 何に決めたか
- 検討した代わりの案: 採らなかった案と理由
- 結果: 判断で何が変わるか、残る制約

状態は、この目録の表の「状態」の列だけに持つ（提案、採用、廃止、置換）。ファイルの中には書かない。
