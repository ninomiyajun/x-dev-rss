# x-dev-rss の起動・確認・停止

パスはすべてリポジトリの根からの相対である。

## 前提

- Node.js の 26 系以上（`package.json` の `engines` が `>=26`）と npm を使う。TypeScript は Node.js が型を除いて直接実行するので、
  ビルドしない。
- 依存は `npm ci` で入れる。
- 待ち受けの先は無い。サーバーではなく、1 回動いて終わるコマンドなので、ホストとポートを選ばない。

## 起動のコマンド

- `npm run start`（中身は `node src/index.ts`）。待ち受けの先を選ぶ引数は無い。すぐ終わるので、前面で実行する。
- 今は、起動すると使い方を 1 行出して終わるだけで、X の取得と Slack への投稿はまだ無い。取得と投稿を作った後の起動の形
  （秘匿値の読み込みを含む）は、最初の機能を作るときにこの節を書き直す。

## 起動の完了の確かめ方

今は、コマンドが終了コード 0 で終わり、出力に `使い方: node src/index.ts` の行が出ることで確かめる。取得と投稿を作った後の
確かめ方は、最初の機能を作るときに決める。

## 止め方と止まったことの確かめ方

1 回動いて自分で終わるので、止める操作は要らない。止まったことは、起動したコマンドが終了コードを返して戻ったことで確かめる。

## 確認用のデータで起動する方法

なし（今のコードはデータを読まず、外部へ通信しない）。取得と投稿を作った後に、X と Slack へ通信せずに決まったデータで
起動する方法は、まだ決めていない。最初の機能の設計で決める。
